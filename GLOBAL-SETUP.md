# Global install — EvolveLoop

After cloning this repository:

```bash
cp mcp/mcp.env.example ~/.cursor/mcp.env
# edit secrets (never commit)
bash scripts/install-agents-global.sh
```

Restart Cursor. Prefer first-time setup via [AGENT.md](AGENT.md).

## What it installs

| Destination | Content |
|-------------|---------|
| `~/.cursor/skills/` | symlinks → `.cursor/skills/` |
| `~/.agents/skills/` | pipeline + `global-skills/` |
| `~/.cursor/commands/` | `/evolve`, `/wiki`, `/mem`, `/prd`, `/planejar`, … |
| `~/.cursor/hooks.json` | orchestrator pickup (wiki-mem **not** always-on in public default) |
| `~/.cursor/rules/` | `evolveloop.mdc` + `wiki-agent.mdc` |
| `~/.cursor/agents.env` | `AGENTS_ROOT`, `ORCHESTRATOR_ROOT` |
| `~/.cursor/mcp.json` | MCP template (secrets from env) |
| `~/.local/bin/agents-orch` | orchestrator CLI wrapper |

## Variables

`~/.cursor/agents.env` (generated by the installer):

```bash
export AGENTS_ROOT="/path/to/EvolveLoop"
export ORCHESTRATOR_ROOT="$AGENTS_ROOT/orchestrator"
# export WIKI_ROOT="/path/to/your-wiki-vault"
# export RAG_REPO_ROOT="$WIKI_ROOT"
```

MCP secrets: `~/.cursor/mcp.env` (never in git).
