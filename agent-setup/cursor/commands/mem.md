# /mem — Wiki memória episódica

Invoca a skill **wiki-mem** (`~/.cursor/skills/wiki-mem/SKILL.md`).

1. Ler `LATEST.md` em `$WIKI_ROOT/.ai/sessions/`
2. Se houver query: `python3 ~/.cursor/hooks/wiki-mem/mem.py search "…"`
3. Contratos/arquitectura → **não** usar só isto; usar `/wiki` / HARD-GATE Wiki
4. Para promover a canónico: `mem.py promote` → append `{Projeto}/log.md`
