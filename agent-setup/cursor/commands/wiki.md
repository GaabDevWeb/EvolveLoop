# /wiki — Wiki grounding

Invoca a skill **wiki** (`~/.cursor/skills/wiki/SKILL.md`).

1. Ler a skill e seguir o ritual (pack → scout/search, ou clarificar se faltar projeto/tópico).
2. Correr `bash ~/.cursor/skills/wiki/scripts/ground.sh …` quando aplicável.
3. Responder no template obrigatório (Fontes, Contratos, GAPs, Pack, Método, Handoff).
4. **Não** usar `wiki vibe` para coding — o Agent Cursor implementa.

Args opcionais após `/wiki`: `scout …` | `pack kernelbot-rag` | `search …` | pergunta livre.
