# Getting started

1. Clone EvolveLoop.
2. Attach [AGENT.md](../../AGENT.md) to your agent and follow DETECT → … → REPORT.
3. Set `WIKI_ROOT` if you use Wiki grounding.
4. Invoke `/evolve` for orchestration cycles; `/wiki` for grounding.

See the root [README.md](../../README.md) for architecture, limitations, and profiles.
