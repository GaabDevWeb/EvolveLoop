# Concepts

- **Capability IR** — planner output consumed by the Execution Engine  
- **PDA** — multi-role agent tree with inherited GATE_BUNDLE  
- **KnowledgeBackend** — retrieval interface; Wiki is the default implementation  
- **Evidence Bus** — on-disk JSON for gate decisions  
- **EvolveLoop** — observation-first evolution subsystem (V1 frozen)  
- **Profile** — personalization boundary (not a second runtime)
